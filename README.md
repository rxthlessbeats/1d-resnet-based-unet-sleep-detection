# 1D ResNet U-Net sleep detection

Installable package for the 1D ResNet U-Net in `notebooks/unet/unet.ipynb` (Child Mind Institute sleep-state detection). Each window contains a day of 5-second samples with 180 minutes of context on each side. The network's first stride is 12, so the head predicts one score per minute. Onset is a negative target and wakeup is positive. Training is masked MSE with group splits by `series_id`, then peak picking and the competition event-detection AP.

The second-stage LightGBM notebooks under `notebooks/` are unchanged research notes. They are not a console command.

## Setup

Torch is locked to the CPU wheel index so the resolve does not pull CUDA libraries.

```bash
uv sync
uv run pre-commit install
```

For a CUDA wheel, point the same source at a CUDA index and lock again:

```toml
[[tool.uv.index]]
name = "pytorch-cpu"
url = "https://download.pytorch.org/whl/cu128"
explicit = true
```

```bash
uv lock && uv sync
```

Optional extras that the training path does not import: `uv sync --extra nni` and `uv sync --extra notebooks`.

## Commands

Place `train_series.parquet` and `train_events.csv` where you pass them (the notebooks expect those names at the repo root).

```bash
uv run sleep-unet prepare --series train_series.parquet --events train_events.csv --out data/prepared
uv run sleep-unet train --prepared data/prepared --out artifacts
uv run sleep-unet evaluate --prepared data/prepared --checkpoints artifacts --events train_events.csv
uv run sleep-unet predict --series test_series.parquet --events train_events.csv --checkpoints artifacts
uv run sleep-unet demo
```

`demo` builds two synthetic series and runs prepare, one epoch, post-processing, scoring, and checkpoint inference. It does not need the competition files.

`--seed` is the number of independent training seeds. Out-of-fold predictions average those seeds; inference averages the saved fold checkpoints using one model instance.

Each training run needs an empty output directory. Inference loads exactly the seeds and folds declared in `meta.json` and fails if any are missing. Extra checkpoint files are ignored.

`evaluate` requires the saved `oof.npy` and verifies that the prepared windows, targets, masks, minute mapping, features, and normalization match the training run. Older OOF caches without a dataset fingerprint require retraining. Evaluation and NNI event AP use plain peak picking so held-out labels cannot influence time priors. Only `predict` uses training-event priors; pass `--peaks-only` to omit them and `--events`.

Loss and RMSE include only valid minutes. Missing calendar days contribute zero context rather than copying another observed day.

Prediction uses the training normalization bounds saved in checkpoint metadata. Older metadata without `norm_min` and `norm_max` must be updated from the matching prepared dataset or regenerated by training.

`train --nni` reads `batch_size`, `initial_channels_num`, and `lr` from an NNI trial and reports event AP. Each trial writes under its own `NNI_OUTPUT_DIR`, using the basename of `--out`. `unet_nni/config.yml` calls that command. Install the `nni` extra first.

## Notebooks

`notebooks/unet/unet.ipynb` runs the shared preparation, training, OOF evaluation, and prediction functions. Set paths and training counts in its parameter cell. Rerunning training requires a fresh `CHECKPOINT_DIR`.

The other notebooks in `notebooks/` remain research notes. Their first cell finds the repository root and imports `sleep_unet`.
